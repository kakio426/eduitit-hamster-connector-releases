# 에듀잇티 햄스터 연결 프로그램

로봇 체험 부스의 Windows x64 무설치 연결 보조도구입니다.

- 체험 화면과 다운로드: https://eduitit.com/robot-booth/
- ZIP 전체 해제 → START_CONNECTOR.cmd → 웹 체험 열기
- Python을 별도로 설치하지 않아도 됩니다.
- 인터넷 없이 체험 열기 버튼으로 PC에 포함한 화면을 사용할 수 있습니다.
- 실물 카메라·햄스터·그리퍼는 현장 보정과 시험이 필요합니다.
- 설치형·자동 업데이트 프로그램이 아닙니다. 새 버전은 ZIP을 다시 받습니다.

이 저장소에는 배포 파일과 공개 검증 절차만 보관합니다. 비공개 운영 소스나 사용자 설정·학습 데이터는 올리지 않습니다.
